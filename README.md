Portfolio Angel celestin

Portfolio personnel présentant les projets, le CV et les informations d'Angel Celestin.

Description : 

Ce projet est un site vitrine en HTML et CSS qui contient :
- une page d'accueil
- une page CV
- plusieurs pages de projet
- une carte mentale interactive des projets

Structure du projet : 

- index.html : page d'accueil du portfolio
- cv.html : page présentant le CV
- projet1.html à projet5.html : pages de présentation des différents projets
- style.css : styles de la page d'accueil et de la mindmap
- projet.css : styles des pages de projet
- Documents/: fichiers annexes
- CV Angel Maximilien Celestin.pdf : version PDF du CV

Techonologies utilisées : 

- HTML5
- CSS3
- Font Awesome pour les icônes

ce que angel celestin (le client) peut changer

il peut modifier :
- le texte dans les fichiers HTML,
- les couleurs et le design dans style.css et projet.css,
- les images et documents dans le dossier Documents/.
